# 📖 Overview

The **Podcast Scheduler App** is a Java-based desktop application that simplifies podcast management by allowing users to create, edit, organize, and schedule podcast episodes efficiently.

Developed using **Object-Oriented Programming (OOP)** principles, the project demonstrates clean architecture, custom exception handling, inheritance, interfaces, and modular software design.

Whether managing regular episodes or bonus content, the application provides an organized workflow for podcast scheduling and publishing.

---

# ✨ Features

- 🎙️ Create podcast episodes
- 📅 Schedule episode publication dates
- ✏️ Edit episode information
- 🗑️ Delete existing episodes
- 📋 Display all scheduled episodes
- ⭐ Support for both Regular and Bonus episodes
- 🔄 Publishable interface implementation
- ⚠️ Custom exception handling
- 🏗️ Object-Oriented design using inheritance and polymorphism
- 🖥️ Simple desktop interface

# 🧩 Object-Oriented Programming Concepts

This project demonstrates several important OOP concepts:

### ✅ Encapsulation
Data members are protected inside classes using getters and setters.

### ✅ Inheritance
Specialized episode types extend the base `Episode` class.

### ✅ Polymorphism
Objects are handled through common parent classes and interfaces.

### ✅ Abstraction
The `Publishable` interface defines publishing behavior.

### ✅ Exception Handling
Custom exceptions improve application reliability.
