# EpisodeRepository.java

## Purpose

Manages all podcast episodes within the application.

## Responsibilities

- Create new episodes.
- Store episodes.
- Schedule episodes.
- Prevent scheduling conflicts.
- Save episodes to a file.
- Load episodes from a file.

## Related Classes

- Episode
- RegularEpisode
- BonusEpisode
- ScheduleConflictException
- EpisodePersistenceException
